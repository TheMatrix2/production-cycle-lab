# Лаборатория производственного цикла

Интерактивная учебная модель варианта 6: три вида движения, диаграммы операций, зависимость времени и условной эффективности от размера передаточной партии.

## Запуск

Нужен Node.js 18 или новее.

```sh
npm install
npm run dev
```

Откройте адрес, показанный в терминале. Проверка расчётов: `npm test`; сборка: `npm run build`.

Последняя передаточная партия может быть неполной. Подробности о расчётах, перерывах и ограничениях доступны в приложении по кнопке «Алгоритм и формулы». Экономические показатели являются учебной моделью, не полной себестоимостью. Интернет нужен только для загрузки необязательных шрифтов; приложение работает и без них.

## Публикация на GitHub Pages

Загрузите проект в репозиторий GitHub, выберите в настройках репозитория Settings → Pages → Build and deployment → Source: GitHub Actions. При отправке изменений в ветку `main` приложение проверяется, собирается и публикуется автоматически. Для запуска публикации вручную выберите Actions → Deploy to GitHub Pages → Run workflow. Сайт на GitHub Pages публичен.
